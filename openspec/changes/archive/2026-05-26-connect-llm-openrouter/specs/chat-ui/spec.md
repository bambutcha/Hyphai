## ADDED Requirements

### Requirement: Ошибки LLM в UI
UI SHALL показывать локализованные сообщения при сбоях генерации ответа (LLM не настроен, недоступен, rate limit, таймаут).

#### Scenario: LLM не настроен
- **WHEN** API возвращает ошибку о ненастроенном LLM (503)
- **THEN** пользователь видит понятный текст на русском в баннере с возможностью повторить отправку

#### Scenario: Таймаут LLM
- **WHEN** API возвращает ошибку таймаута LLM (504)
- **THEN** текст сообщения остаётся в composer; баннер предлагает повторить

#### Scenario: Ожидание генерации
- **WHEN** пользователь отправил сообщение и API обрабатывает LLM
- **THEN** UI показывает состояние отправки (sending) до получения ответа или ошибки
