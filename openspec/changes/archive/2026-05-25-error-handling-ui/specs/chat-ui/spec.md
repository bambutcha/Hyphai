## ADDED Requirements

### Requirement: Загрузка данных
UI SHALL показывать индикатор загрузки при первичной загрузке диалогов и истории сообщений.

#### Scenario: Загрузка списка диалогов
- **WHEN** пользователь вошёл и список диалогов ещё не получен
- **THEN** в сайдбаре отображается индикатор загрузки вместо пустого списка

#### Scenario: Загрузка сообщений
- **WHEN** пользователь выбирает диалог
- **THEN** в области сообщений показывается индикатор загрузки до получения истории

### Requirement: Понятные ошибки
UI SHALL показывать человекочитаемые сообщения об ошибках вместо сырого JSON или технического текста API.

#### Scenario: Ошибка сети
- **WHEN** API недоступен (network error)
- **THEN** пользователь видит сообщение о недоступности сервера с возможностью повторить

#### Scenario: Ошибка авторизации
- **WHEN** API возвращает 401 на защищённый запрос
- **THEN** пользователь видит сообщение об истёкшей сессии и перенаправляется на экран входа

#### Scenario: Ошибка валидации
- **WHEN** API возвращает 400/422 с полем `error`
- **THEN** UI показывает текст из `error`, а не полный JSON-ответ

### Requirement: Повтор при ошибке
UI SHALL предоставлять действие «Retry» для восстановления после сбоя загрузки или отправки.

#### Scenario: Повтор загрузки диалогов
- **WHEN** загрузка списка диалогов завершилась ошибкой
- **THEN** пользователь может нажать Retry и список загрузится снова

#### Scenario: Повтор отправки
- **WHEN** отправка сообщения завершилась ошибкой
- **THEN** текст остаётся в поле ввода и пользователь может отправить снова

### Requirement: Статус realtime-соединения
UI SHALL информировать пользователя о разрыве WebSocket-соединения с активным диалогом.

#### Scenario: WebSocket отключён
- **WHEN** соединение WebSocket закрывается во время активного диалога
- **THEN** в заголовке области сообщений отображается индикатор «Disconnected»

#### Scenario: WebSocket подключён
- **WHEN** WebSocket успешно установлен
- **THEN** индикатор показывает состояние «Connected» или скрывается

### Requirement: Закрываемый баннер ошибок
UI SHALL показывать ошибки чата в dismissible-баннере, который можно закрыть вручную.

#### Scenario: Закрытие баннера
- **WHEN** отображается баннер ошибки в основном интерфейсе чата
- **THEN** пользователь может закрыть его кнопкой dismiss без перезагрузки страницы
