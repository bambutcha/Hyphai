## MODIFIED Requirements

### Requirement: Echo-ответ ассистента
Система SHALL автоматически создавать ответ ассистента после каждого сообщения пользователя. Текст echo-заглушки SHALL быть на русском языке, пока LLM не подключён.

#### Scenario: Echo после отправки
- **WHEN** пользователь шлёт сообщение в диалог
- **THEN** сохраняется сообщение assistant с русскоязычным echo-подтверждением получения текста
