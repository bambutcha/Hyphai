## ADDED Requirements

### Requirement: Welcome при отсутствии диалогов
UI SHALL показывать полноценный welcome-экран вместо неактивной панели чата, когда у пользователя нет ни одного диалога.

#### Scenario: Первый визит
- **WHEN** список диалогов пуст и загрузка завершена
- **THEN** в основной области отображается welcome с пояснением и кнопкой «Новый чат», поле ввода сообщений отсутствует

#### Scenario: CTA создаёт диалог
- **WHEN** пользователь нажимает CTA на welcome-экране
- **THEN** создаётся новый диалог и открывается панель сообщений

### Requirement: Выбор диалога
UI SHALL показывать отдельный empty-экран, когда диалоги есть, но ни один не выбран.

#### Scenario: Диалоги есть, выбор не сделан
- **WHEN** в сайдбаре есть хотя бы один диалог и `activeId` не задан
- **THEN** основная область показывает экран «Выберите диалог» или «Создайте новый», без disabled composer

### Requirement: Анимация empty states
UI SHALL плавно показывать empty-экраны (fade-in), с уважением `prefers-reduced-motion`.

#### Scenario: Появление welcome
- **WHEN** отображается welcome-экран
- **THEN** контент появляется с плавной анимацией (или мгновенно при reduced-motion)
