## MODIFIED Requirements

### Requirement: Понятные ошибки
UI SHALL показывать человекочитаемые сообщения об ошибках на **русском языке** вместо сырого JSON, технического текста API или английских строк по умолчанию.

#### Scenario: Ошибка сети
- **WHEN** API недоступен (network error)
- **THEN** пользователь видит сообщение о недоступности сервера на русском с возможностью повторить

#### Scenario: Ошибка авторизации
- **WHEN** API возвращает 401 на защищённый запрос
- **THEN** пользователь видит сообщение об истёкшей сессии на русском и перенаправляется на экран входа

#### Scenario: Ошибка валидации
- **WHEN** API возвращает 400/422 с полем `error`
- **THEN** UI показывает локализованный текст ошибки на русском, а не английский оригинал из API

#### Scenario: Ошибка валидации 2
- **WHEN** Когда пользователь вводит некорректный по шаблонам email или пароль и переходит к следующему полю без нажатия кнопки enter
- **THEN** UI предупреждает пользователя локализованным текстом, что введенные данные некорректны и как должно быть правильно
