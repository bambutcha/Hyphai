## Why

Интерфейс Hyphai уже на русском, но ошибки API и браузерная валидация форм остаются на английском («Invalid credentials», нативные подсказки `required`/`type=email`). Для хакатона и реального использования нужен единый русскоязычный UX: понятные сообщения об ошибках и аккуратная inline-валидация полей входа и регистрации.

## What Changes

- Слой локализации ошибок API: маппинг известных кодов/текстов (`Invalid credentials`, `Session expired…`) на русские сообщения
- Кастомные поля формы (`FormField`) с inline-ошибками в стиле Hyphai вместо нативных HTML5-подсказок
- Клиентская валидация email, пароля и имени до отправки запроса
- Обновление `AuthScreen` — без `required`/`minLength` браузера, ошибки под каждым полем
- Локализация общих ошибок чата (баннер, retry, сеть) на русский

## Capabilities

### New Capabilities

- `auth-ui`: экран входа/регистрации с кастомной валидацией и русскими сообщениями

### Modified Capabilities

- `chat-ui`: требование «Понятные ошибки» — все пользовательские сообщения об ошибках на русском

## Impact

- `apps/web/lib/errors.ts` (или расширение `api.ts`) — словарь локализации
- `apps/web/components/ui/FormField.tsx` — переиспользуемое поле с ошибкой
- `apps/web/components/AuthScreen.tsx` — новая форма
- `apps/web/components/ChatApp.tsx`, `ErrorBanner`, sidebar/pane — русские fallback-сообщения
- API и формат ответов бэкенда не меняются

## Non-goals

- Полная i18n-система (react-intl, переключатель языка)
- Локализация API-ответов на бэкенде
- Валидация полей чата (отправка сообщений) — только auth-форма
- Локализация UI-лейблов сайдбара («New chat», «Retry») — отдельный change при необходимости
