## MODIFIED Requirements

### Requirement: Визуальный стиль
UI SHALL использовать тёмную тему с акцентами hyphae/грибницы: градиенты, мягкие тени, улучшенная типографика и визуальная иерархия. Все интерактивные элементы SHALL иметь явные affordances: `cursor: pointer` при hover, усиленный hover-state, `focus-visible` при keyboard navigation.

#### Scenario: Тёмная тема по умолчанию
- **WHEN** пользователь загружает приложение
- **THEN** тёмный фон с emerald-акцентами, декоративный фоновый градиент в области чата

#### Scenario: Карточки диалогов
- **WHEN** пользователь видит список диалогов
- **THEN** элементы списка выглядят как интерактивные карточки с hover-состоянием и курсором pointer при наведении
