## MODIFIED Requirements

### Requirement: Ветка диалога (fork)
Система SHALL позволять создать новый диалог как ветку от существующего сообщения с сохранением `parent_id` и `fork_from_message_id`. В новый диалог SHALL копироваться **только** подпоследовательность сообщений от начала ленты до выбранного сообщения **включительно**, в каноническом порядке (`created_at` по возрастанию, при равенстве — `id` по возрастанию). Сообщения, идущие **после** выбранного в ленте, MUST NOT попадать в ветку.

#### Scenario: Fork с сообщения
- **WHEN** пользователь выбирает «Ветка» на user или assistant message
- **THEN** создаётся новый диалог; `parent_id` указывает на исходный диалог; `fork_from_message_id` = выбранное сообщение

#### Scenario: Усечённая история
- **WHEN** в диалоге 6 сообщений (3 пары user/assistant) и пользователь создаёт ветку с 2-го сообщения
- **THEN** в новом диалоге ровно 2 сообщения в том же порядке; сообщения 3–6 отсутствуют

#### Scenario: Fork с последнего сообщения
- **WHEN** пользователь создаёт ветку с последнего сообщения в ленте
- **THEN** новый диалог содержит полную историю исходного диалога (эквивалент «до конца»)

#### Scenario: Одинаковый created_at
- **WHEN** несколько сообщений имеют одинаковый `created_at`
- **THEN** порядок определяется по `id`; fork не включает сообщения после выбранного в этом порядке
